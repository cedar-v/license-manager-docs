# 项目全局信息

## 项目简介

本仓库是 License Manager 的官方文档站，基于 VitePress 构建，用于承载产品介绍、使用指南、SDK 接入说明、API 入口、客户案例、政策协议与中英文文档。

当前文档站更偏资料索引和产品说明。后续需要逐步增强为面向开发者的接入中心，让客户工程师可以围绕在线激活、离线激活、SDK 使用、许可证校验、错误排查和上线检查完成完整接入闭环。

## 技术栈

| 类型 | 内容 |
|------|------|
| 文档框架 | VitePress |
| 构建工具 | Node.js / npm |
| 图表能力 | Mermaid / vitepress-plugin-mermaid |
| 默认语言 | 中文 |
| 多语言 | 中文根目录 + `docs/en/` 英文目录 |
| 静态资源 | `docs/public/` |

## 目录结构说明

| 路径 | 说明 |
|------|------|
| `docs/index.md` | 中文首页 |
| `docs/guide/` | 中文指南文档 |
| `docs/guide/why/` | 战略洞察类文档 |
| `docs/guide/cases/` | 客户案例文档 |
| `docs/policies/` | 服务协议、隐私声明、账号协议等政策文档 |
| `docs/en/` | 英文文档 |
| `docs/public/` | 图片、站点清单、SEO 文件和自定义 CSS |
| `docs/.vitepress/config.mjs` | VitePress 站点配置、导航和侧边栏 |
| `docs-blog/` | 运营文章、推广材料和内部参考资料 |
| `.ai/` | 需求、设计、交付和项目协作说明 |
