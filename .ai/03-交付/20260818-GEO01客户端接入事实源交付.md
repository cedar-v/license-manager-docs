# GEO-01 客户端接入事实源交付

## 交付结论

GEO-01 已完成。官方文档和官网已统一为当前客户端接入规则：产品公钥为产品级公钥；首次在线激活、试用或恢复使用同次响应中的 `public_key` 验证 `license_file`，完整校验后配对保存；心跳返回新许可证时复用本地已保存公钥，完整校验通过后只替换许可证；纯离线场景成对交付许可证和产品公钥。

## 行为对照

已按当前实现核对：

- `ActivateResponse`、试用响应和按设备指纹恢复响应包含 `license_file` 与 `public_key`。
- `HeartbeatResponse` 包含可选 `license_file`，不包含新公钥。
- 产品关联许可证复制并使用产品密钥材料签名，心跳重新生成许可证时继续使用该许可证对应的签名密钥。
- C# SDK 支持首次在线激活不预置公钥，接收并缓存响应公钥。
- C++ SDK 支持首次在线激活由接口返回并缓存公钥，心跳更新复用当前验证器公钥；固定公钥钉扎保留为可选能力。

本次未修改服务端或 SDK 代码，未盘点各 SDK 默认硬件指纹字段，也未重新设计在线、心跳、混合或纯离线模式。
