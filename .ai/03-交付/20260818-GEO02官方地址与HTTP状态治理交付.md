- 启用 `certbot-renew.timer`，续期演练通过；增加续期成功后校验并重载 Nginx 的 deploy hook。
- 普通产品体验统一指向 `https://lic.cedar-v.com/`；私有化演示改为联系入口。
- `llms.txt` 不再公开明文 HTTP 演示地址。
- 部署工作流增加链接检查，并排除 `.ai`、`.nvm`、`ops`、`scripts` 等非公开目录；现有私有仓库部署凭据和连接方式按确认保持不变。

### 官方文档

- 官网引用统一为 `https://cedar-v.com/`。
- 线上体验与 API 基址统一为 `https://lic.cedar-v.com/`。

### 链接检查

两个仓库均增加无第三方依赖的 Node.js 检查脚本并接入 GitHub Actions：

- 站内目标不存在、旧官方域名、明文演示入口直接失败。

- 忽略 `.ai`、构建缓存、构建产物和运营素材等非公开源文件。
