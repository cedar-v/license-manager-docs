# 产品公钥内置对接文档更新交付

## 交付结论

官方开发者中心已统一采用产品级公钥接入方式：开发者从产品页面获取公钥，在开发或构建阶段把公钥写入客户端代码或只读资源，客户端始终使用这把公钥验证许可证；激活、试用和恢复响应中的 `public_key` 无需处理。

## 主要更新

- AI 原生 API 协议提示词新增 `PRODUCT_CODE`、`PRODUCT_PUBLIC_KEY_PEM` 必填项。
- AI 提示词明确要求把产品公钥写入对接代码，并忽略接口响应中的公钥。
- 模板 A 至 D 均补充产品公钥占位项，并删除面向用户的测试清单。
- 离线模板改为只导入 `license_file`，不再导入公钥。
- 在线激活、本地验签、原生 API、离线接入、故障排查和生产检查清单统一更新。
- C# SDK 文档按当前正式能力说明固定产品公钥配置与许可证验签流程。
- 中文与英文许可证结构文档统一产品公钥和 `active` 状态规则。

## 固定安全边界

1. 正式授权码应关联产品。
2. 产品公钥来自管理端产品页面。
3. 产品公钥随客户端程序只读交付。
4. 接口响应中的公钥直接忽略。
5. 许可证使用内置产品公钥验签。
6. 验签成功后继续检查状态、有效期和设备指纹。
