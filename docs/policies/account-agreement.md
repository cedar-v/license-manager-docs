# 雪松授权云账号协议

生效日期：2026 年 7 月 1 日

本账号协议适用于用户注册、登录、认证、使用、管理、注销雪松授权云账号及租户账号的全过程。用户勾选同意、注册账号、登录平台、创建租户、加入企业、使用客户自助服务或继续使用账号功能，即表示已阅读、理解并同意本协议。

本协议是[雪松授权云服务协议](./service-agreement.md)的组成部分。两者约定不一致的，涉及账号注册、认证、安全和权限管理的事项，以本协议为准；涉及服务购买、授权交付和平台使用的事项，以服务协议及订单、合同约定为准。

## 一、账号类型

雪松授权云可能提供以下账号或身份类型：

1. 租户管理员账号：用于创建和管理租户、产品、套餐、授权码、许可证、成员、角色、订单和系统配置。
2. 租户成员账号：由租户管理员邀请或创建，在授权范围内使用管理端功能。
3. 客户自助账号：企业客户或个人客户用于购买、查询订单、管理授权码、激活设备、查看许可证和处理售后事项。
4. API 或系统凭证：用于系统集成、自动化调用、SDK 接入、服务端交互或客户端授权校验。

不同账号类型的功能、权限、数据可见范围和责任边界可能不同，以平台实际配置、角色权限、接口文档、订单或合同约定为准。

## 二、注册条件

用户注册账号时，应满足以下条件：

1. 具备与注册和使用服务相适应的民事行为能力。
2. 提供真实、准确、完整、合法有效的手机号、验证码、密码、企业信息、联系人信息或其他必要资料。
3. 如代表企业、组织或客户注册，应已取得充分授权，并有权代表该主体使用雪松授权云。
4. 不得使用他人手机号、邮箱、企业名称、商标、身份信息或其他资料进行冒用、混淆或欺诈性注册。
5. 不得批量注册、恶意注册、绕过验证码、使用自动化工具抢占账号或干扰平台正常注册秩序。

我们有权根据安全、合规、风控、反欺诈或服务开通需要，要求用户补充、更新或验证注册资料。

## 三、账号资料与认证

用户应及时维护账号资料，确保手机号、邮箱、企业名称、联系人、开票信息、收货或交付信息保持有效。因资料错误、失效或未及时更新导致无法登录、无法接收通知、无法开票、授权交付错误或服务中断的，由用户自行承担相应后果。

平台可根据业务需要提供手机号验证码、密码、邮箱、企业认证、人工审核、双因素认证或其他认证方式。用户应按页面提示完成认证。认证通过不代表我们对用户资质、信用、经营能力、软件产品合法性或履约能力作出保证。

## 四、密码、验证码与凭证安全

用户应妥善保管账号密码、短信验证码、邮箱验证码、登录令牌、API 密钥、SDK 配置、许可证私钥、支付凭证和管理员权限，不得向无关第三方泄露、出租、出借、出售或共享。

用户发现账号被盗、验证码泄露、API 密钥异常、成员权限失控、许可证私钥泄露、非本人操作或其他安全风险时，应立即修改密码、撤销凭证、调整权限并联系平台处理。我们可根据风险情况采取强制下线、重置密码、暂停接口、冻结账号、限制敏感操作或要求重新认证等措施。

## 五、权限与租户管理

租户管理员应合理设置成员角色和权限，遵循最小权限原则。成员在其权限范围内进行的产品配置、授权码生成、许可证签发、订单操作、设备解绑、客户资料查看、API 调用或数据导出等行为，视为租户授权行为。

租户内部因权限分配、员工离职、外包协作、客户交付、误操作、内部审批或数据归属产生的争议，由用户自行解决。我们可根据平台记录、法律法规、司法机关或行政机关要求协助提供必要信息，但不当然介入用户内部管理纠纷。

## 六、账号使用规范

用户使用账号时不得实施以下行为：

1. 冒用、盗用、共享、买卖、出租或转让账号。
2. 绕过平台身份验证、风控、权限控制、计费规则或授权限制。
3. 通过账号实施攻击、爬取、刷量、短信轰炸、验证码试探、接口滥用或其他影响平台稳定性的行为。
4. 上传、配置、分发违法违规、侵权、恶意、欺诈或损害第三方权益的软件授权内容。
5. 利用账号管理、出售或交付来源不明、未经授权、侵犯知识产权或违反出口管制、行业监管要求的软件产品。

如账号存在违规或高风险行为，我们有权根据情节采取提醒、验证身份、限制敏感功能、暂停登录、冻结账号、暂停 API、限制授权交付、终止服务或保存证据等措施。

用户可按照平台流程申请注销账号。注销前，用户应处理未完成订单、发票、授权交付、客户服务、成员关系、数据备份、API 调用和其他未结事项。账号注销可能导致无法登录、无法查看历史订单、无法管理授权、无法恢复数据或无法继续使用相关服务。

存在以下情形之一的，我们可暂停、限制或拒绝账号注销：

1. 账号存在未完成订单、未结算费用、退款、争议、投诉或违法违规调查。
2. 账号涉及司法、行政、监管、仲裁、审计或安全事件处理。
3. 注销可能损害其他用户、客户、成员或第三方合法权益。
4. 法律法规或平台规则要求继续保存相关记录。

账号注销后，我们将根据法律法规、服务协议、隐私声明和数据保留规则处理相关信息。
