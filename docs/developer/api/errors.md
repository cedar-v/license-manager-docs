# 错误码

本页按开发者接入场景整理常见错误。完整错误码以 Swagger 和服务端实际响应为准。

## HTTP 状态码

| 状态码 | 常见场景 | 处理建议 |
|--------|----------|----------|
| 400 | 请求参数无效 | 检查必填字段、JSON 格式和字段类型 |
| 401 | 未认证或凭证无效 | 检查需要鉴权的接口是否携带有效令牌 |
| 404 | 授权码或许可证不存在 | 确认授权码、许可证密钥和环境是否一致 |
| 409 | 授权状态冲突 | 检查授权码是否锁定、过期、超过激活次数，或许可证是否撤销 |
| 500 | 服务端异常 | 保留请求信息和时间，联系管理员排查 |

## 激活相关错误

| 现象 | 可能原因 | 处理建议 |
|------|----------|----------|
| 授权码不存在 | 授权码输错，或来自另一个环境 | 核对授权码和 API 地址 |
| 授权码已过期 | 授权有效期已结束 | 续期或重新生成授权码 |
| 授权码被锁定 | 管理员锁定授权码 | 联系管理员确认锁定原因 |
| 激活次数已满 | 当前授权码已达到最大设备数 | 解绑旧设备、扩容或更换授权码 |
| 硬件指纹缺失 | 请求中未传 `hardware_fingerprint` | 客户端生成并提交硬件指纹 |

## 本地校验相关错误

| 现象 | 可能原因 | 处理建议 |
|------|----------|----------|
| 许可证文件不存在 | 首次激活未完成或本地文件被删除 | 重新激活 |
| 签名验证失败 | 产品公钥缺失或与许可证不匹配、许可证损坏、验签方式错误 | 在线首次获取时核对同次响应数据；心跳或启动时核对本地配对数据；离线时核对同批交付物 |
| 设备不匹配 | 当前硬件指纹发生变化 | 走换机、解绑或重新授权流程 |
| 授权已过期 | 当前时间超过许可证结束时间 | 续期或重新签发 |
| 客户端时间异常 | 本机时间被调整 | 提醒用户校准系统时间 |
