# 离线授权

适合工厂内网、隔离网络等客户设备无法访问授权服务的场景。客户软件通过导入许可证完成授权，运行时无需联网。

**客户设备离线，不等于必须私有化部署。** 交付人员可以在联网环境使用雪松授权云签发许可证，再交给离线设备。

## 1. 为自己的软件接入离线授权

用 AI 编程工具打开自己的软件项目，进入 [AI 接入指南](./ai-quickstart.md)，复制完整的“协议提示词”和[模板 D：纯离线部署 + 手工导入](./ai-quickstart.md#template-d)，填入产品编码和需要保护的业务功能。

如果还需按授权控制功能配置、使用限制或自定义参数，再追加[模板 E](./ai-quickstart.md#template-e)。

接入后的软件需要具备：

- **显示或导出设备指纹**：使用稳定的硬件指纹，不使用 MAC、IP 等网络信息。
- **导入许可证和产品公钥**：先验签，再检查授权状态、有效期和设备指纹，全部通过后配对保存。
- **运行时本地校验**：每次启动及关键业务执行前检查授权，到期或校验失败时阻断受保护功能；更换许可证失败时保留旧文件。

纯离线客户端不调用激活、心跳、试用或按指纹恢复等在线接口。指纹可以复制或导出，不要求使用统一的“离线请求文件”格式。

## 2. 给客户交付授权

1. **取得设备指纹**：客户在实际使用软件的设备上获取指纹，交给交付人员。
2. **创建绑定设备的许可证**：交付人员在可访问授权平台的环境中，为对应产品准备授权码，设置使用期限及按需使用的高级规则，再根据客户设备指纹创建许可证。后台操作见[操作指南](../guide/operating_guide.md)。
3. **配对交付**：将许可证和对应产品公钥一起交给客户，不交付产品私钥。
4. **导入并验证**：客户在原设备上导入，确认受保护功能正常使用，并检查许可证中的实际有效期。

::: tip 有效期以许可证为准
不要把“客户导入文件”当作在线激活。手工创建的离线许可证在后台即视为已激活，不能默认从客户首次导入时才开始计时。
:::

## 3. 离线使用的限制

| 场景 | 处理方式与边界 |
| --- | --- |
| 续期或调整功能、额度 | 重新签发并交付更新后的许可证，由客户导入；不会自动同步。 |
| 后台锁定或撤销 | 无法使已交付到纯离线设备的旧许可证立即失效；如需实时远程管控，应选择联网与心跳方案。 |
| 更换设备或指纹变化 | 获取新设备指纹，重新办理授权。 |
| 修改系统时间 | 本地时间可能被回拨，客户端需要考虑时间回拨检测；纯离线无法依赖服务器实时校时。 |

正式交付前，至少验证：正常导入、错误公钥、错误设备、文件篡改、授权到期，以及更新文件失败后旧许可证仍保留。
