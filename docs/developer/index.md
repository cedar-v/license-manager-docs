# 开发者中心

将雪松授权云接入您的软件。新项目推荐使用 **AI 原生 API 接入**：不安装 SDK，让 AI 根据完整协议和业务模板直接完成开发。

::: tip 推荐接入方式
1. 在 AI 编程工具中打开需要加入授权功能的软件项目
2. 在平台创建或选择产品，并为授权码关联产品
3. 打开 [AI 原生 API 快速接入（推荐）](./ai-quickstart.md)
4. 将产品编码填入提示词，再选择一个业务模板交给 AI
5. 让 AI 按在线响应或离线交付方式取得产品公钥并完成代码实现
:::

## 按业务选择

| 您的业务 | 接入方式 |
|---|---|
| 激活后定期检查是否到期 | 在线激活与本地校验 |
| 先试用，之后输入授权码激活 | 在线试用 |
| 需要续期、撤销或配置更新 | 心跳与远程授权控制 |
| 部署环境完全离线 | 指纹采集与许可证手工导入 |
| 按许可证控制功能或用量 | 读取许可证业务配置 |

不确定如何选择时，先看 [业务接入方式指导](./business-guidance.md)；确定业务后，直接进入 [AI 原生 API 快速接入](./ai-quickstart.md) 复制对应模板。
