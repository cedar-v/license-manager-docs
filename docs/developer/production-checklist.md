## 上线结论

上线前至少满足：

1. 正常激活和本地校验通过。
2. 主要失败场景都有可读提示。
3. 授权无效时不会放行受限业务功能。
4. 日志足够支持排查，但不泄露敏感信息。
5. 客户支持团队知道如何处理过期、锁定、换机和离线授权问题。
