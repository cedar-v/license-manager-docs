# 客户案例

已有软件、组件或设备配套工具，都可以从对应场景了解授权怎么接入。客户案例中的示例规则不代表所有客户的实际配置。

## JAR 包、C++ 插件与 SDK

没有独立界面的代码组件，也可以按期限、设备数量和功能版本交付授权。

[查看组件商业授权案例 →](./20260905-component-licensing.md)

## 硬件设备厂商

设备生产企业使用企业版，为自己生产的设备所关联的软件工具管理授权。

[查看设备配套软件案例 →](./20260905-equipment-software-licensing.md)

## 机器视觉检测软件

按设备、使用期限和算法模块管理授权，并根据工厂现场选择联网或离线交付。

[查看机器视觉授权方案 →](./machine-vision-licensing.md)

## 独立开发者

从发放授权码到客户端激活，把软件交付过程连接起来。

[查看软件销售与授权场景 →](./indie-developer-monetization.md)
