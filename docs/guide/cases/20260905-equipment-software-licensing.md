# 硬件设备厂商如何管理配套软件授权

**销售硬件设备的企业，同样有软件授权管理需求。** 授权对象可以是随设备交付的软件工具，也可以是运行在设备内部的软件系统。

## 客户背景

一家硬件设备生产企业采用了雪松软件授权管理系统企业版，为自己生产的设备所关联的软件工具进行授权管理。

这类产品交付的不只是硬件，还有配套的软件能力。本文隐去客户名称与具体设备型号，以下以同类场景说明授权思路，不代表该客户已使用全部功能。

## 哪些软件可以纳入授权

以电磁测量仪等仪器设备为例，软件可以有两种形态：

- **设备配套工具**：安装在电脑上，用于连接设备、查看测量数据或进行分析的软件。
- **设备内的软件系统**：运行在设备内部，提供操作界面、数据处理或专业功能的软件。

无论软件运行在哪里，授权管理的对象都是软件的使用权与功能权限，而不是硬件本身。

## 如何应用授权管理

厂商可以在需要保护的软件中接入授权校验，再根据交付约定设置规则：

- **使用期限**：约定软件或选配功能可以使用多久。
- **设备绑定**：将授权绑定到软件实际运行的设备，限制跨设备复制使用。
- **功能配置**：根据客户购买的版本开放相应功能，由软件读取授权配置并执行。

例如，设备配套分析工具可以区分基础分析与高级分析模块，按客户购买的功能交付授权。这是可采用的方案示例，并非该客户的具体配置。

配套工具如果运行在电脑上，默认绑定的是运行软件的电脑，不能直接等同于绑定外接仪器。需要绑定具体仪器时，应另行明确设备识别与校验方案。

## 对设备厂商的价值

这类客户案例说明，软件授权并不局限于独立销售的软件。硬件厂商也可以把配套软件纳入授权管理，让设备交付与软件使用权限对应起来，并为后续的软件续期、功能选配提供管理基础。

涉及设备运行的软件，应提前定义授权失效时的处理方式，保留安全操作与数据保存能力，避免直接中断正在进行的设备任务。
