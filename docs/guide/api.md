# 接口文档

如果您正在做客户端授权接入，推荐先使用 [AI 原生 API 快速接入（推荐）](/developer/ai-quickstart.md)，将完整协议提示词和适合您业务的模板交给 AI。需要逐项查阅接口时，再进入 [开发者中心 API 总览](/developer/api/)。

## 平台入口

默认对接雪松授权云平台：

```plaintext
https://lic.cedar-v.com/
```

完整接口字段、响应结构和实时更新以平台接口文档为准。
